# Resume Evaluator — Code Review Exercise

A single-file TypeScript script that scores candidate resumes against a job description using the OpenAI API.

## Instructions

- You'll have **~15 minutes** to discuss the contents of `main.ts`.
- Don't run or rewrite the code — just identify issues/improvements and articulate how you'd fix them.
- You can open `main.ts` directly in the GitHub web UI -- no need to clone anything.
